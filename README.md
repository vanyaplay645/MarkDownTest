# Овощи

## Почему стоит есть овощи
### Польза для здоровья

*Свежие* / _Свежие_ овощи полезнее консервированных — в них больше витаминов.

**Морковь** / __Морковь__ улучшает зрение благодаря бета-каротину. А ***капуста*** / ___капуста___ богата витамином C и укрепляет иммунитет.

~~Сладкие перекусы~~ лучше заменять овощами — это полезнее для организма.

#### Витамины и минералы

`витамин C` содержится в болгарском перце и брокколи. Полезные вещества лучше усваиваются из свежих продуктов.
